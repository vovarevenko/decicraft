# Дециметр — PoC

Браузерный прототип песочницы «как Minecraft», но мир собран из **кубиков 10 × 10 × 10 см**
(игровой дециметр), а сложные мелкие вещи — инструменты, предметы, животные, двери — из
**кубических сантиметров**. Цели нет: заходите, исследуйте, копайте, рубите, стройте и смотрите,
как ощущается мир такого масштаба.

## Запуск

```bash
npm install
```

```bash
npm run dev
```

Откройте <http://localhost:5173>. Нужен браузер на Chromium (Chrome, Edge, Arc) или свежий
Firefox/Safari. Игра использует `SharedArrayBuffer`, поэтому её нужно открывать через `npm run dev`
или `npm run preview` (они отдают заголовки COOP/COEP) — простой статический сервер не подойдёт.

Первый запуск генерирует мир и строит геометрию (пара секунд, есть индикатор). Кнопка «Начать»
захватывает курсор, Esc отпускает его и ставит игру на паузу.

## Что есть в мире

Карта 128 × 128 м поделена на четыре области:

- **Заброшенный городок** (северо-запад) — магазин, гараж, почта, жилые дома, развалины, сарай,
  остановка, ржавая машина, фонари, заросший сад. В домах — шкафы, ящики и холодильники с
  находками; у въезда стоит ящик с первыми инструментами.
- **Лиственный лес** (северо-восток) — дубы, берёзы, сосны, сухостой, валуны, папоротники, грибы.
- **Луг с прудом** (юго-запад) — цветы, высокая трава, камыш, пруд глубиной около 2 м.
- **Скалистые холмы** (юго-восток) — сосны на склонах, скальные выходы.

Что можно делать:

- **Копать и рубить.** Лопата снимает слои грунта (дёрн, земля, глина, песок, гравий), кирка колет
  камень, кирпич, бетон и асфальт, топор рубит дерево. Подрубленное дерево падает целиком, а
  здание без опоры обрушивается. Яма рядом с прудом заполняется водой.
- **Строить.** Любой добытый материал можно поставить кубом от 1 до 5 вокселей.
- **Крафт** (Tab): палки, верёвка из травы, каменный топор, факелы, доски, костёр, жареное мясо
  (только рядом с горящим костром).
- **Предметы:** фонарик и факел светят в руке, еду можно съесть, газеты — прочитать.
- **Животные:** пугливые косули замечают вас издалека (подкрадывайтесь пригнувшись) и убегают
  от шума — например, от упавшего дерева или разбитого стекла. Бродячих собак можно погладить
  или угостить.
- **Смена дня и ночи:** ночью темно — пригодятся фонарик, факел или костёр. Глубокая ночь идёт
  в 4 раза быстрее дня.
- **Звук:** шаги по разным материалам, удары инструментов, фоновые звуки каждой области — всё
  синтезируется прямо в браузере.

## Управление

| Клавиша | Действие |
|---|---|
| WASD | ходьба |
| Shift | бег |
| Пробел | прыжок, в воде — всплыть |
| Пробел (удерживать у уступа) | забраться на уступ высотой до 1,2 м |
| C | присесть (с края не упадёте), в воде — нырнуть |
| V | полёт сквозь стены (Пробел — вверх, C — вниз, Shift — быстрее) |
| ЛКМ (удерживать) | копать / рубить / ударить |
| ПКМ | поставить материал / использовать предмет (съесть, прочитать, включить фонарик, поставить костёр) |
| E | взаимодействовать: двери, ящики, костёр, собака, подобрать предмет |
| Q / Shift+Q | выбросить один предмет / всю стопку |
| [ и ] | размер ставимого куба (1–5 вокселей) |
| R | точный режим (ломать по одному вокселю) |
| 1–9, колесо мыши | слот панели |
| Tab или I | инвентарь и крафт |
| M | карта |
| T (удерживать) | ускорить время суток |
| F3 или \` (клавиша Ё) | отладочная информация |
| Esc | пауза |

## Параметры отладки в URL

`?seed=123` — другой мир, `?pos=64,64` — точка появления в метрах (x, z) или `x,y,z`,
`?yaw=90&pitch=-10` — направление взгляда в градусах, `?time=21` — час суток,
`?autostart` — сразу запустить цикл без стартового экрана и захвата курсора (для автоматических
проверок, контекст игры доступен как `window.__game`).

## Устройство

Подробная спецификация и контракты модулей — в [ARCHITECTURE.md](ARCHITECTURE.md).

- Мир 128 × 51,2 × 128 м = 1280 × 512 × 1280 вокселей, чанки 32³, хранятся в `SharedArrayBuffer`
  и читаются воркерами без копирования.
- Генерация мира идёт параллельно в веб-воркерах по тайлам 12,8 × 12,8 м.
- Рендер — three.js, октодерево уровней детализации (10 / 20 / 40 см), жадный мешинг с AO и
  «небесным светом» в воркерах, процедурные узоры поверхностей в шейдерах.
- Отделение срубленного дерева, подготовка его падения и укладка на землю считаются в отдельном
  воркере; главный поток только записывает изменения в мир.
- Инструменты, предметы, животные и двери собраны из 1-сантиметровых вокселей.
- Звуки синтезируются через Web Audio, без файлов.
